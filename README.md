# Northbridge Commerce Ltd Website

Premium Next.js website for a UK-focused independent e-commerce business.

## Before launch

1. Change the company name in `lib/site.ts`.
2. Replace `partnerships@[companydomain].co.uk` with the real business email.
3. Replace `https://example.co.uk` in metadata, robots.txt and sitemap.xml with the real domain.
4. Connect `components/EnquiryForm.tsx` to your email/CRM provider. The current form validates locally and intentionally does not send personal data anywhere.
5. Replace any placeholder legal wording with reviewed UK legal documents.
6. Add the real company details, registered office information and other details only if you want them publicly displayed.
7. Add a real favicon/OG image if desired.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Build

```bash
npm run build
npm start
```
